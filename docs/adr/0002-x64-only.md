# 0002 — Support the x64 game client only

- **Status:** Accepted
- **Date:** 2026-11-10
- **Deciders:** project owner

## Context

Grim Dawn ships both a 32-bit `Grim Dawn.exe` and a 64-bit `x64\Grim Dawn.exe`. GDIA's HookDll is x64. The owner runs the x64 client. Supporting both architectures would require two hook builds, two injection paths, and two test matrices.

## Decision

v1 supports the x64 client only. If the application detects an x86 game process, it refuses to attach and shows a clear message asking the user to launch the x64 client.

## Consequences

- x86 players are unsupported in v1.
- The installer and launcher can default to `x64\Grim Dawn.exe`.
- A future x86 hook remains possible without changing the data layer.
